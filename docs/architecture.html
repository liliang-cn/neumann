neumann · 按冯·诺依曼计算机组织的常驻 Agent

虚拟核心（vCore）不停地取指、执行、写回，一条指令就是一次模型调用。每个模型服务商一组 vCore，数量按服务商的承受能力自动伸缩；工具挂在总线上异步执行；任务状态每步写回主存。

A：指定大核组，要调慢工具 B C D：B、C、D 走默认的小核组 虚线槽位：窗口允许时随时扩出 vCore I/O 在途 / 退避 / 收件箱有插话 / 冷却 熔断 / 崩溃

vCore / 指令无状态的 goroutine，随时增减 / 一次模型调用，或一批工具调用的派发
大小核核心组：一个服务商一组；任务按亲和性调度，熔断时迁往 Fallback 组
拥塞窗口每组 vCore 上限 W：成功一个窗口加 1，收到 429 减半，空闲 30 秒的 vCore 退役
进程 / 寄存器任务（TCB）/ 服务商无关的中立消息格式，由适配器翻译
调度每组就绪队列分交互、后台两级，按就绪时间轮转，后台任务等 30 秒自动提级；满了 Submit 返回 ErrBusy
DMA + 中断工具调用异步执行，不占 vCore；完成后进中断队列，唤醒任务
L1 / L2服务商 prompt cache（前缀逐字节不变）/ 只读工具结果缓存
主存 / 磁盘SQLite 组提交，每步写回 / 长期记忆，作为工具挂在总线上
